# SPACE-INVADERS-SHOOTING-GAME
VITYARTHI PROJECT
OVERVIEW OF THE PROJECT:- This is the game oriented project which is created by using the "PYTHON" language. It is incorporated with the 6 classes which have their respective technical functionalities which are as follows:-
1.BULLET CLASS:- It is made for the shooting functionality in the program to destroy the invaders(enemy) attacking the player.
2.PLAYER CLASS:- It is made as the equipment to fire the bullet on the invaders in the program.
3.INVADER CLASS:- It is meant for the  enemy functionality in the program attacking on the player.
4.INVADER FLEET CLASS:- It is made to control the invaders movement in the program.
5.SCOREBOARD CLASS:- It controls the score gained by the player after eliminating the invaders in the game.
6.GAME ENGINE CLASS:- It is made to control the entire game loop and the collision setup(bullet hitting the invader) of the game.
FEATURES:- It is incorporated with the error handling, user friendly score generator along with perfect graphical and animation oriented objects.
TECHNOLOGIES/TOOLS USED:- The technologies/tools used are:-
1.Pygame module (from the python library).
2.Random module(from the python library).
3. sys module(from the python library).
STEPS TO INSTALL & RUN THE PROJECT:- The steps are as follows:-
1.Download the project.
2.Ensure that the user's computer should have "IDLE" installed in it.
3.Install required libraries.
4.Run the project in IDLE.
INSTRUCTION FOR TESTING:-
